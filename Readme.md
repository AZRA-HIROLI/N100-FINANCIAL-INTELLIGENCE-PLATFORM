# 📈 Nifty 100 Fundamental & Valuation Analytics Platform

An end-to-end Python analytics engine and 8-screen Streamlit dashboard for analyzing, screening, benchmarking, and valuing the 92 companies in the NIFTY 100 universe.

---

## 🚀 Quickstart & Dashboard Execution

### Prerequisites
- Python 3.10+
- Dependencies: `pandas`, `numpy`, `matplotlib`, `plotly`, `streamlit`, `pytest`, `openpyxl`

### 1. Run Streamlit Dashboard
Launch the multi-page dashboard locally on `localhost:8501`:
```bash
streamlit run src/dashboard/app.py
